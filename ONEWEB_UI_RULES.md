# OneWebUI Design System & Agent Guidelines

Единый источник правды для веб-сервисов экосистемы One.
- Репозиторий: [https://github.com/pipych/oneweb-ui](https://github.com/pipych/oneweb-ui)
- Витрина компонентов: [https://webui.onelaunch.pp.ua](https://webui.onelaunch.pp.ua)
- Локальный путь к библиотеке: ../oneweb-ui (или git-зависимость `github:pipych/oneweb-ui`)

## 1. Токены и цвета
- Фон страницы: `#090b0e`
- Базовая поверхность (Card, Modal, Drawer, Tab container): `#14171c`
- Приподнятая поверхность (Elevated, Input inside card, Icon shapes): `#181c23` или `#1c222b`
- Акцентный цвет (One Lime): `#c0ff00`
- Приглушенный текст / плейсхолдеры: `#8e8e93`
- Белый текст: `#ffffff`

## 2. Жесткие правила геометрии и обводок
- НИКАКИХ ОБВОДОК (No borders): border, outline, ring запрещены на всех сплошных элементах. Исключение — только стекло/blur (`border-white/[0.04]`).
- НИКАКИХ ОСТРЫХ УГЛОВ: минимальный радиус в системе — 12px.
- ФОРМА PILL (`rounded-full`): все кнопки, все инпуты, табы, бейджи — без исключений.
- КАРТОЧКИ И МОДАЛКИ: `rounded-[28px]` или `rounded-[32px]`.

## 3. Компоненты и логика
- **Иконки**: Material Symbols Rounded (FILL: 1), строго через `<OneIcon name="..."/>`.
- **Поля ввода (Input)**:
  * Всегда имеют видимый фоновый шейп: `variant="base"` (`#14171c`) на фоне страницы, `variant="elevated"` (`#181c23`) внутри карточек.
  * Правый экшен — строго круглая иконка-кнопка (`rounded-full w-8 h-8`).
- **Бейджи (Badge)**:
  * Без обводок, полупрозрачный фон цвета статуса (~10-15%), индикаторная точка и текст одного цвета.
- **Табы (Tabs)**:
  * Капсульный контейнер, плавно скользящая подложка активного таба, активный текст `#c0ff00`, круглые счетчики.
- **Виджеты (Bento)**:
  * Small: горизонтальная строка с иконкой в скругленном квадрате слева.
  * Square: компактный квадрат, иконка на шейпе сверху слева, стрелка перехода справа, заголовок и капс-сабтайтл строго прижаты к левому нижнему углу.
  * Large: полноразмерная карточка, иконка в заголовке строго БЕЗ шейпа.
- **Навигация**:
  * Десктоп: хедер из OneDash (без лимита вкладок, без свечения).
  * Мобилка: нижний плавающий таббар (СТРОГО не более 5 вкладок).
  * Mobile FAB: только на мобилке, справа внизу строго над таббаром, круглый, только иконка.
- **Оверлеи и Меню**:
  * Десктоп: модалка по центру (крестик есть только если нет кнопки отмены), меню «три точки» открывает дропдаун.
  * Мобилка: ВСЕГДА шторка снизу (Bottom Sheet), никаких дропдаунов не существует, закрытие свайпом вниз, крестиков на мобилке нет. Контент шторки не залезает под таббар.
